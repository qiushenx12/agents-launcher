## 修复: Claude Code 对话界面字体大小设置不生效

**问题**: APP 字体大小设置只影响 `--font-size-base/title/small`，ClaudeConversationPane 使用自己 scoped 内硬编码的 `--claude-content-font-size: 14px` / `--claude-meta-font-size: 12px`，完全独立于用户设置。

**修复**:
1. `src/App.vue` - `applyAppFontSize()` 中新增设置 `--claude-content-font-size` (appFontSize+1) 和 `--claude-meta-font-size` (appFontSize-1) 到 documentElement
2. `src/components/claude/conversation/ClaudeConversationPane.vue` - 将硬编码值改为引用全局变量的 fallback 写法 `var(--claude-content-font-size, 14px)`

这样默认 APP 字体 13px 时对话内容仍是 14px、元信息 12px，与原来一致；用户调 APP 字体后 Claude 对话也会同步缩放。
